# Multi-tenancy

_This doc will be filled in with the exact click-path once Phase 1 (multi-tenancy proven
end-to-end) is complete. Placeholder for now — see `docs/architecture.md` for the model._

Each tenant gets its own database, its own content, and its own active theme/enabled modules.
Tenants are created from **Multi-Tenancy → Tenants → Add Tenant** in the admin of the Default
tenant (the platform super-admin site).
